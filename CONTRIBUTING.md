# Contributing

- File an issue before a pull request unless the change is editorial.
- One section per PR where possible. Section files live in `spec/` and are numbered; do not renumber sections in a working draft — add a subsection instead.
- Conformance language is RFC 2119. If you add a MUST, add the reason to the PR.
- Keep the specification vendor-neutral. Product names, company names and marketing language will be asked to be removed.
- Schemas in `schemas/` are normative once referenced from the spec; examples in `examples/` are illustrative.
- By contributing you agree your contribution is licensed under the repository licences (CC BY 4.0 for text, Apache 2.0 for schemas and code).
